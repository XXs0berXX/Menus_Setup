Emotion-adaptive menus: experiment launcher

Five menus, each matched to one emotional state, plus a standard drop-down as the control. All six show the same 36-page store, the same colours and the same type, so the menu structure is the only thing that changes. Rationale and references are in README.md.

This page is for researchers only, because it names the emotions. Participants should only see the store page. The store URL shows the menu's structural name (e.g. menu=radial), never the emotion.
